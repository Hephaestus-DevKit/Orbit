## Harness 责任边界

`AgentModelRequest` 统一主模型、压缩摘要、失败日志摘要和提交说明的请求入口。辅助调用不再漏记费用，并继承整个运行的取消信号与重试归属。

`SessionUsageLedger` 在有价格时预留输入估算和输出上限，根据剩余预算缩减输出额度；不足时在调用提供商之前拒绝。预留与结算共享同一本账，收到累计用量后只结算一次。费用记录使用请求发起时的价格，避免跨定价时段按结束时间重新计价。

预留金额通过 `pendingCostEstimate` 持久化。连接丢失、取消或缺少用量时保留不确定费用；明确的认证、额度、限流和参数拒绝才释放预留。恢复会话不会重新授予这些在途预算，也不会把缺失用量说成已知零元。

`StepRunner` 持有实际执行承诺的所有权，超时只结束等待。被取消但仍在执行的操作会阻止冲突工具、后置 Hook、新运行、会话切换和回滚，直到执行真正结束；明确声明可并行的只读幂等工具仍可并发。测试覆盖取消后迟到结果、所有权释放、回滚拦截和循环纠错提示。

交互式工具参数修正移入 `AgentToolProtocol`，模型请求准入移入独立模块；主循环规模继续减少，架构上限从 4820 收紧到 4780 行。MCP 文件的上限仅增加 3 行，对应 `prefault` 引发的一处格式换行，没有增加调度职责。

`AgentModelRequest` 与 `SessionUsageLedger` 已纳入关键代码覆盖率检查，沿用现有门槛。此次关键代码行覆盖率 87.13%、分支覆盖率 80.4%、函数覆盖率 90.7%，全部通过。

## 浏览器验收发现

浏览器切回静态标签页或恢复历史时可能清空画面，却收不到新的 screencast 事件。切换时激活目标标签页，并补充首帧截图回退；核对运行代次、标签页、页面 ID 和尺寸，避免取消、导航或缩放后接收迟到画面。

此前的内置浏览器还会输出裁掉部分高度的实时画面，直接展示会造成点击坐标错位。检测到尺寸不符时改取完整视口截图，合并同一页面尚未完成的截图请求。滚动回归同时检查页面实际滚动位置与画面更新，避免依赖不同截图编码器产生完全一致的 JPEG。

部分旧版浏览器原生下拉框、日期和颜色选择器在读取状态前已经关闭。点击后允许读取获得焦点的受支持控件，同时要求点击位置位于控件边界内；仍拒绝隐藏、禁用、只读、多选和非弹出式列表。中英文及繁体中文流程均纳入浏览器验收。关闭页面弹窗时，测试也明确等待原点击操作完成，再将共享页面交给 Agent，避免把弹窗消失误当成所有操作已经结束。

## 仍需推进的范围

- 这里是基于本地价格和输入估算的预算约束，并非提供商硬消费上限。未知价格、收费工具的在途开销以及独立子代理的共享预算池仍需进一步统一。
- 不合作的进程内代码仍不能被强行终止。本轮阻止同一运行器继续交叠操作；完整隔离还需要工作进程或工作区事务，不能据此宣称任意扩展都已获得进程隔离。
- DeepSeek 图片 token 投影、跨子任务统一预算以及可复现的长期任务评测仍是后续架构工作。
